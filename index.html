Project 01 — AWS, self-directed

A web tier that heals itself

High availability

An internet-facing Application Load Balancer distributes traffic to an Auto Scaling Group spanning two Availability Zones. Losing a zone does not lose the site.

No static credentials

Instances read from a private S3 bucket through an IAM role and instance profile scoped to one bucket ARN. No access keys stored anywhere on the host.

Boot-time provisioning

A launch template and user data script install Apache and pull application content from S3 on first boot, so a replacement instance is identical to the one it replaced.

Health checks that mean something

ELB health checks on the Auto Scaling Group, so an application returning errors gets replaced — not just a host that stopped responding.

What broke, and why

terminated an instance in us-east-1aThe ASG launched a replacement and the ALB re-registered it. No loss of availability during the swap.

boot-time S3 pull failed silentlyThe launch template had no IAM instance profile attached. The instance came up healthy at the OS level and served nothing — a reminder that a passing EC2 status check is not a passing application.

timeout vs. connection refusedA timeout points at the security group or the network path. A refusal means the packet arrived and nothing was listening. Knowing which one you have cuts the search in half.
